# Build inputs

Only inputs required to reproduce the build are included. The supplied public form/CSS/JavaScript/logo and extracted unfilled agreement terms are retained for provenance. Original other-org routing IDs have been removed from config.js. The original Word document, unrelated org metadata and all actual applicant evidence are excluded.

The extracted source terms retain their original dates as reference material. The builder produces year-neutral general wording and uses config/agreement.json for the current event. The perfect-freehand bundle retains its MIT licence.

Text line endings are normalised to LF for reproducible checkouts.
